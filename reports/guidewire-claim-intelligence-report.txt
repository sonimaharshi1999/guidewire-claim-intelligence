  Guidewire Claim Intelligence - ML-Powered Claim Triage & Fraud Detection
======================================================================

Author: Maharshi Soni
Category: machine-learning
Difficulty: advanced

----------------------------------------------------------------------
DESCRIPTION
----------------------------------------------------------------------
ML-powered claim intelligence engine for P&C insurance. Predicts claim severity, recommends adjuster assignment, estimates reserves, and flags fraud risk using anomaly detection. Trained on synthetic ClaimCenter data covering Auto, Homeowners, Workers Comp, and more.

----------------------------------------------------------------------
TECH STACK
----------------------------------------------------------------------
  - scikit-learn
  - pandas
  - numpy
  - fastapi
  - uvicorn
  - pydantic
  - matplotlib
  - pytest

----------------------------------------------------------------------
FEATURES
----------------------------------------------------------------------
  * Claim severity prediction (1-5 scale)
  * Adjuster recommendation by expertise
  * Reserve estimation
  * Fraud risk scoring with Isolation Forest
  * FastAPI REST API
  * Feature importance explanations

----------------------------------------------------------------------
SAMPLE INPUT
----------------------------------------------------------------------
  Claim attributes

  Example:
    curl -X POST /score -d '{"lob": "PersonalAuto", "loss_amount": 15000}'

----------------------------------------------------------------------
SAMPLE OUTPUT
----------------------------------------------------------------------
  Claim intelligence scores

  Example:
    {"severity": 3, "fraud_score": 12, "adjuster": "Auto Specialist", "reserve": 18500}
